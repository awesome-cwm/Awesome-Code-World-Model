📊 Benchmarks & Evaluation

Compare the task, submitted artifact and evidence of success. These suites test different capabilities; their scores are not interchangeable.

Video reconstruction & inverse graphics

What observable scene structure and motion survive video-to-code reconstruction?

[2026-10] ✅PhysCodeGym: Benchmarking Coding Agents for Physically Verifiable 4D Reconstruction · Code · Data

PhysCodeGym — 156 videos across rigid, liquid, deformable and wind-driven motion → Executable Blender simulation. Checks: Visual metrics, object/event rubrics, native physical measurements; 43 tasks with counterfactual checks.

[2026-10] ✅Video2World: Benchmarking Coding Agents for Interactive World Modeling from Embodied Videos · Project · Code · Data

Video2World — 222 reconstruction instances from 189 embodied videos → Simulation scene + physical settings + robot behavior. Checks: Geometric fidelity, dynamic fidelity and functional task correctness.

[2026-10] ✅4DCodeBench: Benchmarking Agents on Inverse Graphics of Dynamic Scenes · Code · Project · Data · Data

4DCodeBench — 100 real + 100 synthetic videos → Executable dynamic graphics program. Checks: Appearance, 2D/3D geometry and motion; synthetic reference-world comparisons.

[2026-09] ✅BVB: Benchmarking Agentic Video Understanding via Programmatic Reconstruction in Blender · Code · Project

BVB / Blender-VideoBench — 288 indoor videos; agent sees video frames only → Animated Blender scene + camera. Checks: Dual VQA for retained facts; V-JEPA latent similarity for layout/motion.

Executable code & simulation corpora

What reusable programs, paired observations and verification records are available?

[2026-06] ✅🌟(Code vs. video diffusion for inverse physics and stable extrapolation) MPMWorlds: Material-Point-Method Simulations for Inferring and Extrapolating Physical Dynamics · Project

The code-versus-diffusion comparison separates inferring material parameters from extrapolating stable dynamics in 2D MPM simulations.

[2026-10] ✅3DCodeVerse: Exploring 3D Worlds as Code · Project · Code · Data

A 3D coding corpus and verification harness connect editable assets to spatial inspection. The project reports 269,597 executable programs expanded into roughly 2.03M code–condition pairs, with 3DCodeBench evaluation splits held out; those are distinct counting units.

[2026-10] ✅PhySimCode: A Benchmark and Evaluation Method for Physics Video to Code Generation · Code · Project · Data

Video plus an engine identifier must yield physical laws, parameters and runnable simulation code. The paper describes 160,614 generated samples; the linked public evaluation release contains 2,430 videos across 162 phenomena.

[2026-05] ✅3DCodeBench: Benchmarking Agentic Procedural 3D Modeling Via Code · Code · Project · Data

Text and image references are translated into procedural 3D code. 3DCodeArena adds human preference judgments; successful rendering can still conceal floating or disconnected geometry. A precursor to the 3DCodeVerse data ecosystem.

Construction & verification harnesses

What execution and inspection loop helps an agent build a usable world?

[2026-10] ✅3DCodeVerse: Exploring 3D Worlds as Code · Project · Code · Data

A 3D coding corpus and verification harness connect editable assets to spatial inspection. The project reports 269,597 executable programs expanded into roughly 2.03M code–condition pairs, with 3DCodeBench evaluation splits held out; those are distinct counting units.

[2026-10] ✅Code2Worlds-2: Physically Plausible Agent Harness for Embodied World Simulation · Code · Project

A compiler and simulator critic turn visual 4D scenes into MuJoCo-loadable worlds with collisions, joints and contact. The key advance is operational physical semantics.

[2026-10] ✅AgentGarten: Code Worlds for Evolving Agents · Project

Different simulation backends expose a common neural-rendering interface; agents improve by distilling experience into inherited playbooks.

[2026-09] ❌️Text2Sim: Agentic Physics-Based Simulation Generation with Distilled Expertise

Specialized agents and distilled Debug Cards jointly construct and repair Genesis simulations, including rigid, articulated, deformable and cloth phenomena.

[2026-09] ❌️WorldAgent: Verification-Guided Agentic Physical World Construction

Verification checks world specifications, geometry and simulation states during construction, turning failed obligations into targeted edits and resimulation.

[2026-09] ❌️VeriPhy: Agentic Physical Reasoning for World Model Evaluation and Refinement

Typed obligations and provenance-carrying measurements support auditable physical judgments, including abstention. This is a verification system, not a simulator.

[2026-07] ✅SimWorlds: A Multi-Agent System for Dynamic 3D Scene Creation · Project

A staged Blender construction protocol and runtime inspection expose mechanism failures that visual review alone can miss.

Streaming worlds, renderers & decoders

Is the system expanding world state, generating observations, or only decoding latents?

[2026-10] ✅SolarRenderer: Few-Step Generative Reference Rendering · Project · Code

A reusable structure-conditioned renderer reduces the cost of turning diverse world proxies into observations. The renderer itself does not define world dynamics.

[2026-10] ✅Matrix-Game 4.0: Harnessing Video Models for Real-Time Playable Game Worlds · Project

Executable game mechanics and neural observations are separated; reported key-to-display latency makes this a stronger interaction claim than video throughput alone.

[Date TBC] ✅WorldStream: Building 3D Worlds as You Explore · Project · Project

Hierarchical semantic plans feed local procedural generators as exploration expands. Object identities and accepted edits survive geometry unloading. The planner selects structured capabilities; streaming here means world expansion, and code is still announced as coming soon.

[Date TBC] ✅StreamRender-H3: Interactive Coding Worlds with Real-time Streaming Diffusion Render · Code

A Three.js game engine advances explicit state at a fixed timestep and streams semantic maps into a two-step causal MiniMax-H3 renderer. Engine semantics and reference-image appearance are controlled separately.

[Date TBC] ✅Streaming Code World Model · Weights

A community streaming extension of Code World Model uses causal chunks and four-step distillation. Its README explicitly reports 5.1 seconds per 0.71-second chunk on one H200: streaming does not mean real time.

[Date TBC] ✅H3 Streaming VAE Decoder: Training-Free Streaming without Future Latents · Code

A training-free causal decoding adaptation emits frames without future latents, using cache reuse and brightness correction. The repository also supports NVIDIA’s distilled StreamRender-H3 decoder. This is a decoder component, with no world state or action dynamics of its own.

🧭 Reading Guide & Taxonomy

Code World Model follows intent → executable world → observation. Code as Model follows observation → executable hypothesis → prediction, intervention or verification. A paper can contribute to both directions.

The catalog records seven dimensions: code role, world representation, dynamics authority, construction feedback, interaction contract, evaluation target, and domain. The website provides a simple list with ten broad research topics that can be selected together. Full rationale and scope boundaries: Taxonomy / 中文分类说明.

  • From code to pixels: VideoCoCo → Code World Model → Programmable World Model → Code Video Model → SolarRenderer → Matrix-Game 4.0
  • From observation to mechanism: GIF-MCTS / CWMB → MPMWorlds → Code as Worlds → Video2World → NeoWorld-3
  • From plausible to executable: Code2Worlds → SimWorlds → Text2Sim → WorldAgent → Code2Worlds-2 → WorldSolver
  • Worlds that train agents: RoboGen → FactorSim → SimWorld Studio → AgentGarten
