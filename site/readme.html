🧭 Taxonomy & Reading Guide

Select one research area and optionally a direction, then combine one or more auxiliary tags across Research Challenges, Memory & State, Control & Interaction, Representation & Output, Methods & Training, Runtime & Efficiency, World Setting & Domain, and Evaluation Focus. Tag filters use an intersection and can be combined with publication month, title/author search, and resource badges.

The initial V2 assignments migrate the existing curated metadata and editorial summaries; they are not a new full-text review or a certification of reported capabilities. Taxonomy / 中文分类说明.

  • From code to pixels: VideoCoCo → Code World Model → Programmable World Model → Code Video Model → SolarRenderer → Matrix-Game 4.0
  • From observation to mechanism: GIF-MCTS / CWMB → MPMWorlds → Code as Worlds → Video2World → NeoWorld-3
  • From plausible to executable: Code2Worlds → SimWorlds → Text2Sim → WorldAgent → Code2Worlds-2 → WorldSolver
  • Worlds that train agents: RoboGen → FactorSim → SimWorld Studio → AgentGarten
