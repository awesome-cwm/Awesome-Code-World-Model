🧭 Reading Guide & Taxonomy

Research categories describe the main question. Benchmarks and infrastructure describe reusable contributions. Comparison dimensions describe mechanisms; they are multi-label facets, not a ranking.

DimensionWhat to compare
Role of codeWhat does the code actually do?
World representationWhere is the inspectable state?
Dynamics authorityWhat determines the next state?
Refinement signalWhat signal refines the program or model, during construction or training?
Interaction contractWhat can a user or agent change?
Delivery modeHow is the world or its observations delivered?
Evaluation targetWhat has the paper chosen to measure?
DomainWhich world is being modeled?

Streaming delivery does not establish real-time control. Public resources do not establish an open-source license. Full taxonomy and scope boundaries →

  • From code to pixels: VideoCoCo → Code World Model → Programmable World Model → Code Video Model → SolarRenderer → Matrix-Game 4.0
  • From observation to mechanism: GIF-MCTS / CWMB → MPMWorlds → Code as Worlds → Video2World → NeoWorld-3
  • From plausible to executable: Code2Worlds → SimWorlds → Text2Sim → WorldAgent → Code2Worlds-2 → WorldSolver
  • Worlds that train agents: RoboGen → FactorSim → SimWorld Studio → AgentGarten
